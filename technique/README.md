## 两个源头

- **`../DeveloperRealtimeLog.md`**：按时间流水的工作日志（约 900 行），记录每一笔改动和当次实测数字。**不回改**，只追加。
- **本目录**：把日志里沉淀下来的「知识」抽成主题文档。两者冲突时，以代码为准，再看日志的最近一笔。

## 约定

1. 数字要能复现：写「16.4 tok/s」就要能说清在哪台机器、哪个模型、哪次跑的。
2. 失败要写归因：不是「报错了」，而是「spawn git ENOENT，因为 build:auto 去编译 llama.cpp，而新系统没 git」。
3. 文档里出现的路径一律写绝对路径，避免「在我机器上对」的默认值。
