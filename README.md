## 一、这是什么

QingYaoTP AILauncher 是**一台 Windows 电脑上的纯本地 AI 工作台**：模型跑在本机（llama.cpp），界面是本地网页（内嵌窗口），会话、检索、代码、图片处理全部在本地完成。

它要解决的不是「又一个聊天框」，而是**第一次把本地大模型跑起来这件事**：

- 第一次打开时**自动体检**（CPU / 内存 / 显卡 / 运行库 / 磁盘），推荐这台机器能跑动的模型与上下文；
- 没有模型就**引导下载**（最小的约 470MB），下载完自动加载，**30 秒内看到第一句回答**；
- 之后工具调用、联网、看图、代码工作区、终端、调试工具都在同一个窗口里；
- 出问题不用猜——内置 **23 项体检**，坏在哪一层、怎么办，直接列出来。

## 二、适合谁 / 不适合谁

**适合**

- 想在自己电脑上试本地大模型，但不想折腾命令行、CUDA、Python 环境的人；
- 在意隐私：资料、代码、对话不想上传的人（默认只监听本机 `127.0.0.1`）；
- 想要一个「能审代码 + 能查资料 + 能看图」的小工作台，而不是一个只会聊天的窗口。

**不适合**

- 想要云端顶尖模型（GPT-4o / Claude 级别）的人——本地模型的能力上限由你的机器决定；
- Mac / Linux 用户（当前只支持 Windows 10/11 x64）；
- 多人 / 团队共享使用（当前是单机单用户，没有账号体系）。

## 三、系统要求

| 项 | 最低 | 推荐 |
|---|---|---|
| 系统 | Windows 10 1809+ / Windows 11（x64） | 同左 |
| 内存 | 8 GB（跑 0.5B–1.5B 小模型） | **16 GB 以上**（跑 4B / 9B） |
| 显卡 | 无也可（纯 CPU，较慢） | 支持 Vulkan 的核显或独显（Intel / AMD / NVIDIA） |
| 磁盘 | 2 GB（程序）+ 模型空间 | 预留 10 GB 以上 |
| 运行库 | 缺 VC++ 运行库会自动弹窗引导安装 | — |

> **不需要**安装 Node.js、Python、CUDA。发布包自带运行环境。

## 四、安装（3 步）

**第 1 步：下载**

- 主包：`QingYaoTP-AILauncher-v1.11.0.zip`（**约 122 MB**，SHA256 见发布说明）
- 可选看图包：`QingYaoTP-AILauncher-v1.6.0-vision-pack.zip`（**约 37 MB**，文件名版本与主包不同步是正常的，看图才需要）

**第 2 步：解压到可写目录**

- 推荐 C:\QingYaoTP AILauncher（或任意可写盘）；
- **不要**放在 Program Files，**不要**套两层目录（…\xxx\xxx\`QingYaoTP AILauncher.exe` 这种）。

**第 3 步：双击 `QingYaoTP AILauncher.exe`**

首启会自动：体检硬件 → 嗅探本机已有的 `.gguf` → 没有就引导下载一个小模型 → 下载完自动加载 → 发第一句回答。之后程序常驻托盘，右键可「打开界面 / 停止服务并退出」。

装看图能力（可选）：设置 → 视觉 → 安装视觉增强包… 选中那个 vision-pack zip，装完立刻可用，不用重启。

|---|---|---|
| **本地对话** | 普通问答首字 1.5–2 秒（上下文复用 KV 缓存） | 首字 1.5–2s |
| **深度思考** | R1 / Qwen3 的思考过程折叠显示，可展开看推理 | 取决于模型 |
| **工具调用** | 查时间、算数、读工作区文件、跑代码、调用插件 | 开工具后首字约 7–8s（要多预填工具说明） |

| **资料问答（RAG）** | 把 workspace 里的 md / txt / log / csv / docx / pdf 建索引，回答给出处 | 问之前自动增量更新 |
| **代码审查 + 二次验证** | 流式审查思路 → 问题卡片 → 行高亮 → 一键纠正；不满意还能**质询**、**他人复审**、**云端复审**；也能**勾多个文件 / 整个工作区一起审**（逐文件结论 + 跨文件总览 + 导出 `.multi.review.md`） | 单文件审查 30–50s；多文件约 60–90s/个（2 个小文件约 2–3 分钟，最多 8 个）；质询约 16s/轮；他人复审 60–115s；云端 1.5–3s |
| **看图** | 粘贴 / 拖拽 / 选择图片提问（需装视觉增强包） | 1440×900 截图约 40–60s（图像编码固定走 CPU） |
| **会话管理** | 多会话、自动起标题、历史版本回滚、标题 + 正文搜索、备份到别的盘 | 即时 |
| **调试工具** | 23 项体检（服务 / 系统 / 推理 / 数据 / 扩展 / 发布）、诊断历史、导出诊断包 | 几秒 |

> 还有：**终端 TUI**（`localai tui`；v2.0.0 起自带版本号 + 主程序版本、流式 Markdown/LaTeX 降级渲染、`/` 能力面板、线框输入框与旋转等待动画）、**命令行**（localai "问题"）、**公式**（LaTeX / 化学式）、**朗读（TTS）**、**插件**（plugins 里放一个 `.mjs` 就多一个工具）、**外观自定义**（主色 / 缩放 / 背景 / 任意 CSS）。

## 七、三个上手场景

### 场景 A：让 AI 审一段代码，并对结论「较真」

1. 顶栏「代码」→ 新建一个文件（可选语言，15 种），粘贴代码；
2. 点「模型审查」→ 先流式出「审查思路」，再列问题卡片；问题行在编辑器里高亮，点卡片跳过去；
3. 想一次看多个文件（或整个工作区）：文件列表左边勾选（或点「审查工作区」）→「审查选中」；跑完每个文件一张卡，问题点一条就跳到对应文件对应行，最后还有一段**跨文件总览**（找文件之间的不一致），可「导出多文件复审」带走 `.multi.review.md`；
4. 不满意「一键纠正」也行，或者：
   - 点 **质询**，输入「第 3 行不是 bug，因为…」，让模型逐条回答「成立 / 不成立 / 需验证」+ 依据 + 最小验证方法；
   - 点 **他人复审**，自动换一个模型独立再审，并列两栏，并给出判定：**一致 / 仅一方提出 / 互相矛盾**；
   - 点 **云端复审**（可选，需自己配 OpenAI 兼容 API）：面板会先弹窗告诉你「会把当前文件的代码（已脱敏）发到 <域名>」，确认才发。

> 为什么要有后面三条：模型也会看漏、也会自说自话。换一个模型、让它自我辩护、或者让更大的模型看一遍，都是为了**降低「它说没问题但其实有问题」的概率**。

### 场景 B：问自己的资料

1. 把文档丢进 <安装目录>\`workspace\`（支持 md / txt / log / csv / docx / pdf）；
2. 勾上「调用工具」，问「我的资料里关于 XX 是怎么说的」；
3. 模型会调用检索，并在回答里给出**出处**（文件与片段）。

### 场景 C：看图

1. 设置 → 视觉 装好视觉增强包；
2. 点输入区 **Σ**、或直接粘贴 / 拖拽图片，提问「这张图里有什么」；
3. 看图用的是独立进程，**看完 300 秒没再用会自动退出**，把内存还给你；再用会自动拉起。

## 八、数据在哪 · 怎么备份 · 怎么卸载

| 内容 | 位置 |
|---|---|
| 会话、代码工作区、检索索引 | <安装目录>\`workspace\` |
| 界面状态（缓存、主题、本地设置） | <安装目录>\`data\`（含云端复审配置，**里面有 API Key，别外发**） |
| 运行日志、诊断历史 | <安装目录>\`logs\` |
| 模型 | <安装目录>\`models\`（或你在 `config.ini` 里指定的目录） |

- **备份**：整个安装目录拷走就是完整备份；会话也可以「设置 → 工具 → 会话备份」自动镜像到另一块盘 / U 盘 / 网络盘。
- **卸载**：直接删安装目录。没有注册表项、没有系统服务、没有后台常驻（模型只在本进程内加载）。

## 九、隐私与联网边界

| 行为 | 会不会出网 | 说明 |
|---|---|---|
| 聊天、推理、看图 | **不出网** | 模型与图像编码都在本机 |
| 资料问答 / 检索 | **不出网** | 索引与检索都在本机 |
| 开启「联网」 | 会 | 只有你主动开启时，查询词才发给搜索引擎并读取网页正文；本机与内网地址被拒绝 |
| 下载模型 | 会 | 连 ModelScope（或你给的自定义链接） |
| **云端复审** | 会（默认关闭） | 只有你配置并**每次确认**才发；只发当前文件、发前脱敏；API Key 只存本机、不进日志、不随包发出 |
| 导出诊断包 | **不出网** | 本地 zip，需要你手动发给别人 |

> 默认只监听 `127.0.0.1`，同一局域网的其他设备访问不到。

## 十、常见问题

| 问题 | 处理 |
|---|---|
| 双击没反应 / 一闪而过 | 先看 `logs\app.log`；最常见是缺 VC++ 运行库（安装包已随包）；也可双击 `localai-debug.cmd`（服务没起来也能诊断） |
| 界面白屏 | 端口被占（启动器会自动改口并写回 `config.ini`），或被安全软件拦了本地回环 |
| 发图提示「视觉增强包未安装」 | 设置 → 视觉 → 安装视觉增强包…（约 37MB，装完不用重启）；只看文字可以不管它 |
| 生成很慢 | 设置 → 显卡 看有没有选到独显；上下文别开到 64K 以上；第一次提问要预填充，慢是正常的 |
| 显存 / 内存不够 | 换更小的量化（Q4_K_M）或更小的模型；关掉看图（同一时刻只跑一个重模型） |
| 想换模型 | 顶栏「模型」菜单选一个即加载；行尾「删」可删（默认进回收站，可还原） |
| 审查要等挺久 | 正常：审查是两阶段（先流式给思路、再整理问题清单）；4B 实测单文件 30–50 秒。**多文件**是逐个文件串行审（约 60–90 秒/个），一次最多 8 个、单文件上限 6000 字符——超出的会在计划里列出原因并跳过，可分批审 |
| 审查中提示「正在进行，等它结束再切换模型」 | 这是保护：审查时切模型会把底层权重卸掉导致卡死。等它结束或点「停止」再切 |
| **云端复审报「上游 200 但没有返回内容」** | **v1.8.1 起已修复**：deepseek-flash 这类推理模型会把 token 花在思考上；现在会自动关掉推理并重试。请确认你用的是 v1.11.0 |
| 审查模型里看不到 Phi-4-mini | 有意隐藏：它在 Vulkan 上偶发把服务卡死，不能用 |

## 十一、出问题了怎么自救

1. **顶栏「Debug」**：23 项体检（服务 / 系统 / 推理 / 数据 / 扩展 / 发布），每项写清「从什么时候开始坏 + 怎么办」，还能看诊断历史、导出诊断包（本地 zip，不含密钥）、打开日志目录。
2. **服务起不来**：双击程序目录里的 `localai-debug.cmd`（不需要服务在跑）。
3. **看日志**：`logs\app.log`；崩溃记录在 `logs\crashes\`。
4. 反馈问题时附上**诊断包**和「设置 → 关于」里的版本信息，定位会快很多。

**怎么升级**：下载新 zip → 先退出程序（托盘 → 停止服务并退出）→ 解压覆盖到原目录（保留 `workspace\`、`data\`、`models\` 三个目录即可无损）。目前**没有自动更新**，请以发布说明里的版本号为准。

**质量说明**：这个项目没有 CI 服务器，但**每次发版都跑同一套自动回归**——90 个探针、69 组全量用例、1,468 条断言，覆盖接口、界面、模型、看图与打包产物。

> 2026-11-22 体验优化（未发版）：主页面生成中改为**按 Markdown 块增量渲染**（6000 字单帧 14→0.4 毫秒，长回答不再越答越卡），新增**本轮首字提示**与 设置 → 生成 → **极简流式**。
