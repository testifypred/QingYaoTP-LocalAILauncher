# 代码工作区 UI 升级（2026-11-22）

用户 5 条硬需求（第 6 条为可选，暂缓）：

1. 代码工作区窗口可移动，或做成独立窗口；
2. 模型审查结果按标签页（书签）显示，带模型图标，点击查看该模型意见（或下拉选择）；
3. 代码工作区可缩放，审查栏可自由调比例；
4. 没点「模型审查」直接点「他人复审」时，先自动做一次普通审查作为第 1 个结果，第二次起才算他人复审；
5. 优化代码工作区 UI；
6.（可选，暂缓）独立窗口/独立程序，窗口图标用 LaTeX 的 $F(x)$。

## 落地

| # | 实现 |
|---|---|
| 1 | `.cwBox` 标题栏可拖拽（pointer 事件，`transform: translate`）；`#cwMax` 最大化/还原（双击标题栏也行）；窗口本身 `resize:both`（右下角拖大小）。 |
| 2 | 新增 `#cwResultTabs`：每次「模型审查 / 他人复审 / 云端复审」完成生成一个标签，图标 `∫` / `≠` / `☁` + 模型名；点击标签把该次摘要、问题卡片、判定/对照重新铺回面板。最多保留 8 个。 |
| 3 | 编辑区与审查栏之间新增 `#cwSplitter`：拖动改审查栏宽度（260px ~ 面板宽-380px），双击复位；宽度存 `localStorage.localai.cwReviewWidth`。 |
| 4 | `cwCrossReview()` 先检查有没有当前代码的本地审查结果；没有就先 `await cwReviewCode()`（作为第 1 个结果），再跑他人复审（第 2 个）。 |
| 5 | 标签栏样式、分隔条、最大化按钮、审查头/动作区间距统一；结果标签按类型着色。 |
| 6 | 暂缓：独立窗口/程序需要把 `#codeModal` 抽成独立页面 + 启动器新窗口 + 图标（$F(x)$），工作量另算。 |
