## 六、环境注意事项（重要）

1. **DSH 会话沙箱规则**：exe 位于会话工作区（`D:\LocalModels`）内的进程**不能写工作区**（同一 node.exe 复制到 C:\ 就正常；PowerShell/python 不受影响）。因此：
   - 8099 当前用 `C:\QingYaoTP-AILauncher` 副本；
   - 发布包冒烟/长测试把安装目录复制到工作区外；
   - dist 里的实例在 DSH 会话期间写 `workspace` 会 EPERM（用户关掉 DSH 后正常）。
2. **GUI/服务启动**：用工具内 `Start-Process` 起 GUI launcher 可能让调用挂起（子进程继承 stdio）→ 加 `-RedirectStandardOutput/-RedirectStandardError`，或用计划任务以正常用户令牌启动（本机用 `QYTP-Launcher-Start` 计划任务启动过，用完即删）。
3. **改 CSS**：一律追加在 `</style>` 前；改完用 Node 扫 `<style>` 内 `{`/`}` 平衡（`open==close`），再截图 + 跑目标探针。
4. **改 .ps1**：`build-portable.ps1` / `run-full.ps1` 必须是 **UTF-8 BOM**（PS 5.1）；改完 `[Parser]::ParseFile` 校验 0 错。
5. **探针**：界面探针需要 8099 + 9333 headless Edge；`run-probe-with-edge.ps1` 会自己起 Edge；全量/发布包冒烟设 `PROBE_SKIP_SWITCH=1`。
